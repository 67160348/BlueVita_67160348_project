# BlueVita Store — โปรเจกต์เว็บขายวิตามิน (Starter)

เว็บตัวอย่างธีมฟ้า-ขาว มีหน้าแรก, รายการสินค้า, ค้นหา/กรอง/เรียงสินค้า, หน้ารายละเอียดสินค้า, รีวิวจากผู้ซื้อ, คะแนนสะสม 1 คะแนนต่อรีวิวที่มีสิทธิ์, ตะกร้า, สมัครสมาชิก/ล็อกอิน, ประวัติคำสั่งซื้อ และหน้าแอดมินสำหรับเพิ่ม/ลบสินค้าและเปลี่ยนสถานะคำสั่งซื้อ

## เทคโนโลยี
- Frontend: HTML, CSS, Vanilla JavaScript (แก้ไขง่าย ไม่ต้อง build)
- Backend: Node.js + Express REST API
- Authentication: bcryptjs + JWT
- ข้อมูลตัวอย่าง: JSON files ใน `data/` (เหมาะกับโปรเจกต์เรียน/เดโม ไม่เหมาะกับระบบจริงที่มีผู้ใช้เยอะ)

## วิธีเปิดโปรเจกต์
1. ติดตั้ง Node.js เวอร์ชัน 18 ขึ้นไป
2. แตก ZIP แล้วเปิดโฟลเดอร์ `bluevita_store` ใน VS Code
3. เปิด Terminal ในโฟลเดอร์ แล้วรัน:

   ```bash
   npm install
   npm start
   ```

4. เปิด `http://localhost:3000`

## API หลัก
- `GET /api/products?q=&category=` — ค้นหาและกรองสินค้า
- `POST /api/auth/register` — สมัครสมาชิก
- `POST /api/auth/login` — เข้าสู่ระบบ
- `GET /api/auth/me` — ตรวจ session/token
- `POST /api/orders` — สร้างคำสั่งซื้อ (ต้องล็อกอิน)
- `GET /api/orders/mine` — ดูคำสั่งซื้อของตัวเอง
- `GET /api/admin/orders` — ดูคำสั่งซื้อทั้งหมด (admin)
- `PATCH /api/admin/orders/:id` — เปลี่ยนสถานะ (admin)
- `POST /api/admin/products` — เพิ่มสินค้า (admin)
- `DELETE /api/admin/products/:id` — ลบสินค้า (admin)

## ข้อควรทราบก่อนนำไปใช้จริง
นี่เป็น starter สำหรับการเรียนรู้ ไม่ใช่ระบบ production: ยังไม่มี payment gateway, อัปโหลดรูปภาพ, อีเมลยืนยัน, rate limiting, CSRF/security hardening, database จริง, audit log หรือระบบคืนสต็อกเมื่อยกเลิกคำสั่งซื้อ และไฟล์ JSON ไม่เหมาะกับการเขียนข้อมูลพร้อมกันหลายรายการ ควรใช้ PostgreSQL/MySQL, HTTPS, secrets ที่ปลอดภัย, validation ฝั่ง server, สำรองข้อมูล และทดสอบความปลอดภัยก่อนเปิดให้ลูกค้าจริง

ข้อมูลสินค้าเป็นข้อมูลตัวอย่าง ห้ามเขียนคำกล่าวอ้างว่าสามารถรักษา/ป้องกันโรคโดยไม่มีหลักฐานและการอนุญาตที่เหมาะสม ตรวจสอบฉลากและกฎหมายที่เกี่ยวข้องก่อนจำหน่ายอาหารเสริมจริง


## สินค้าตัวอย่างและการเปลี่ยนรูปภาพ

โปรเจกต์มีสินค้าเดโม 15 รายการใน `data/products.json` และภาพแพ็กเกจคอนเซปต์ที่สร้างไว้ใน `public/images/` ภาพเหล่านี้เป็นภาพประกอบจำลอง ไม่ใช่สินค้าจริงหรือแบรนด์จริง

**เปลี่ยนรูปสินค้า:** นำไฟล์ภาพที่มีสิทธิ์ใช้งานมาใส่ใน `public/images/` (แนะนำ `.webp`, `.jpg` หรือ `.png`) จากนั้นเปิด `data/products.json` แล้วแก้ค่า `image` ของสินค้านั้น เช่น `"image": "/images/vitamin-c.webp"` บันทึกไฟล์และรีเฟรชหน้าเว็บ

ถ้าเพิ่มรูปผ่านหน้าแอดมิน ให้กรอก `/images/ชื่อไฟล์.webp` สำหรับไฟล์ที่อยู่ใน `public/images/` หรือใส่ URL รูปออนไลน์ที่เปิดได้โดยตรง อย่าใช้ลิงก์หน้าร้านหรือหน้าผลการค้นหาแทน URL ของไฟล์ภาพ

สินค้าและราคาทั้งหมดเป็นข้อมูลตัวอย่างสำหรับพัฒนาเว็บไซต์ ไม่ใช่คำแนะนำทางการแพทย์หรือการรับรองประสิทธิผล ควรใช้ข้อมูลจริงที่ตรวจสอบแล้วและภาพสินค้าที่ได้รับอนุญาตก่อนเปิดขาย


## ฟีเจอร์ UI และรีวิวคะแนน (เวอร์ชันปรับปรุง)
- แตะการ์ด/ชื่อสินค้าเพื่อเปิดหน้ารายละเอียดสินค้าแยกเป็นหน้า พร้อมภาพใหญ่ ราคา สต็อก รีวิว และข้อมูลข้อควรทราบ
- ข้อมูลส่วนประกอบ/วิธีใช้ไม่ได้แต่งขึ้นเอง: หน้ารายละเอียดระบุให้ตรวจสอบฉลากสินค้าจริง เพราะรายการในเว็บเป็นข้อมูลตัวอย่าง
- เมนู “คะแนนของฉัน” แสดงคะแนนสมาชิกและสินค้าที่รีวิวได้
- สมาชิกได้รับ 1 คะแนนเมื่อรีวิวสินค้าที่อยู่ในคำสั่งซื้อของตัวเองซึ่งมีสถานะ “จัดส่งแล้ว” และรีวิวสินค้าในคำสั่งซื้อนั้นได้ครั้งเดียว
- เจ้าของร้านต้องเปลี่ยนสถานะคำสั่งซื้อเป็น “จัดส่งแล้ว” ก่อนจึงจะรีวิวได้ (ทำได้ในหน้าแอดมิน)
- ระบบนี้เป็นเดโมเพื่อการศึกษา ใช้ไฟล์ JSON เก็บข้อมูล ไม่เหมาะกับการใช้งานจริงที่มีผู้ใช้/ธุรกรรมจริงจำนวนมาก
- ก่อนเปิดใช้จริง ต้องตั้ง `JWT_SECRET`, `ADMIN_EMAIL`, `ADMIN_PASSWORD` ที่แข็งแรงผ่าน environment variables, เปลี่ยนที่เก็บข้อมูลเป็นฐานข้อมูลจริง และตรวจสอบผลิตภัณฑ์/ฉลาก/ข้อกำหนดที่เกี่ยวข้องก่อนขายจริง
